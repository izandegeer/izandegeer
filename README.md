## About me

Web dev student (DAW) who came from graphic design. I spent years making visuals for football accounts with a big audience, and at some point I wanted to build the tools I was using instead of just the graphics.

Learning Java, SQL, HTML, CSS and JavaScript at school. Outside of it I build my own products with AI: [FC Tools Hub](https://fctoolshub.com) is live with 75K+ users, and [Astrah](https://astrah.app) and [ElevenZZ](https://elevenzz.com) are the next ones.

The design background shows in the work: I care about how things look and feel as much as whether they work.

## Featured Projects

- [FC Tools Hub](http://fctoolshub.com/?ref=wgxgraphics) — Career Mode companion app with 75K+ users: AI-generated challenges, player database & squad tools for EA Sports FC. ⚽
- [Astrah](https://astrah.app) — Club-level football graphics in the browser: lineups, transfers, cards & rankings with a built-in catalog of clubs and players. Fill in, download, post. 🎨
